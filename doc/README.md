# Documentación del proyecto

Documentación colaborativa para el mod de Digimon World (PS1). Empieza por el [esqueleto del proyecto y GDD](PROJECT.md).

## Mapa

- `00_project/` — visión, alcance y organización general.
- `01_gdd/` — especificaciones del diseño del juego.
- `02_design/` — sistemas, progresión, combate y experiencia de usuario.
- `03_content/` — lore, personajes, Digimon, localizaciones, eventos, diálogos y objetos.
- `04_technical/` — herramientas, formatos, compatibilidad, construcción y distribución.
- `05_production/` — hitos, tareas, pruebas y seguimiento.
- `06_references/` — investigación, fuentes y material de consulta.
- `decisions/` — registro de decisiones importantes.
- `templates/` — formatos reutilizables para propuestas y fichas.

## ¿Dónde va cada cosa?

- **Lore/biblia narrativa:** `03_content/lore/README.md`; separa mundo, personajes e historia en sus subcarpetas.
- **Mecánicas y reglas:** `02_design/`.
- **Contenido concreto del juego:** `03_content/`.
- **Cómo se modifica, compila o prueba el juego:** `04_technical/`.
- **Calendario, responsabilidades y QA:** `05_production/`.
- **Fuentes y observaciones del juego original:** `06_references/`.
- **Decisiones aprobadas:** `decisions/`.

Al crear documentos, usa nombres claros y enlaces relativos. Marca cada propuesta como **borrador**, **en revisión** o **aprobada**, e indica responsable y fecha de actualización.
